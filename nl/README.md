# Nederlandse versie

De Nederlandse app hoort op een **aparte GitHub Pages-site**:

**https://lukaspoloki.github.io/oslofjord-huisjes/**

Bronbestanden om te publiceren staan in [`../standalone-huisjes/`](../standalone-huisjes/).  
Publiceren (vanaf deze repo, met push-rechten op `oslofjord-huisjes`):

```bash
./scripts/publish-huisjes.sh
```

In deze repo blijft `/nl/` als kopie / preview; gebouwen zijn hetzelfde als de Poolse app, bewoners staan apart in `nl/data.json` (en in `standalone-huisjes/data.json`).
